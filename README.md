# Bank Next Product Prediction

Предсказание следующего банковского продукта, с которым взаимодействует клиент, на основе последовательности его действий.

Проект выполнен в рамках Kaggle-соревнования **«Следующий клик — Raiffeisen Bank Russia»**. Задача — многоклассовая классификация: предсказать один из 32 целевых продуктов по истории просмотров, кликов и других событий.

## Подходы

В ходе исследования рассмотрены несколько методов:

- **TF-IDF + Logistic Regression** — базовая модель на основе истории событий.
- **LightGBM Ranker** — ранжирование продуктов с использованием статистических и временных признаков.
- **KFold + LightGBM** — ансамбль классификаторов.
- **GRU + Attention + MLP** — нейросетевая модель, объединяющая последовательность последних 512 событий и агрегированные признаки всей истории клиента.

## Результаты

| Модель | Kaggle Public Score |
|---|---:|
| LightGBM Ranker | 0.37067 |
| KFold LightGBM | 0.35833 |
| **GRU + Attention + MLP** | **0.41203** |

Лучший результат получен с помощью GRU, которая учитывает как последовательность действий клиента, так и его долгосрочные предпочтения.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Поместить исходные файлы соревнования в `data/`:

```text
data/
├── train.parquet
├── test.parquet
├── event_dictionary.parquet
└── sample_submission.csv
```

Ноутбуки можно открыть в Jupyter или VS Code. Для полноценного обучения GRU рекомендуется использовать GPU (например, Kaggle).

Исходные данные, обученные модели, кеши и файлы предсказаний не включены в репозиторий.
